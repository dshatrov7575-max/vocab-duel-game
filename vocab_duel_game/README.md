# Vocab Duel — тренажёр русско-английского словаря

Это MVP-пакет игры на Python для запуска в **Google Colab**.

## Что уже реализовано

### 1) Одиночный режим
- загрузка слов из **Google Sheets / CSV**
- выбор темы (`Одежда`, `Офис` и т.д.)
- режим **Изучение**
  - русское слово
  - английский перевод
  - транскрипция
  - кнопка **Произнести**
- режим **Проверка**
  - 6 вариантов ответа
  - после правильного ответа слово произносится
  - кнопка **Далее**
  - таймер прохождения темы
- история прохождений по теме
- сортировка истории по возрастанию времени

### 2) Сетевой режим
- профиль игрока:
  - имя
  - пол
  - "коротко о себе"
  - уровень словаря `1-1000` ... `1-7000`
- поиск напарника **только своего уровня**
- видна информация "коротко о себе" о сопернике
- результаты матчей сохраняются
- история матчей доступна для просмотра
- по завершении двух результатов определяется победитель

## Важное ограничение по Colab

**Полноценная Google-авторизация и устойчивый сетевой режим в "голом Colab" без внешнего сервиса ненадёжны**, потому что:
- Colab-сессии засыпают
- нет постоянного backend-хостинга
- секреты OAuth/Firebase нельзя хранить прямо в коде

Поэтому пакет сделан так:

- **гостевой режим** работает сразу
- **Google-вход** включается после подключения **Firebase Authentication**
- хранение истории сейчас идёт в `SQLite`, что хорошо для MVP/демо
- для постоянного онлайна лучше потом вынести backend на Render / Railway / VPS

## Формат таблицы слов

В Google Sheets должны быть столбцы:

- `topic`
- `ru`
- `en`
- `transcription`

Дополнительно можно:
- `freq_level`

Пример:
| topic | ru | en | transcription | freq_level |
|---|---|---|---|---|
| Одежда | рубашка | shirt | [ʃɜːrt] | 1-3000 |
| Одежда | брюки | trousers | [ˈtraʊzərz] | 1-3000 |

## Как запустить в Colab

1. Загрузите папку в Colab
2. Откройте `vocab_duel_colab.ipynb`
3. Выполните ячейки сверху вниз
4. Игра откроется во встроенном окне Colab

## Как включить Google-вход

1. Создайте проект Firebase
2. Включите **Authentication → Google**
3. Скачайте **service account JSON**
4. В Colab загрузите этот JSON
5. Заполните env-переменные:
   - `FIREBASE_SERVICE_ACCOUNT`
   - `FIREBASE_API_KEY`
   - `FIREBASE_AUTH_DOMAIN`
   - `FIREBASE_PROJECT_ID`
   - `FIREBASE_STORAGE_BUCKET`
   - `FIREBASE_MESSAGING_SENDER_ID`
   - `FIREBASE_APP_ID`

После этого кнопка **Войти через Google** заработает.
