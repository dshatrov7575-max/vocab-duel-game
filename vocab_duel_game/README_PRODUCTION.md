# Деплой Vocab Duel в продакшен

## Самый простой путь: Render

### Что получится
- постоянная ссылка вида `https://...onrender.com`
- приложение доступно другу по одной ссылке
- Colab больше не нужен
- одиночный режим работает сразу
- сетевой режим работает в гостевом режиме сразу

## 1. Подготовь проект
Загрузи этот проект в GitHub как новый репозиторий.

## 2. Зайди на Render
- создай аккаунт
- нажми **New +**
- выбери **Blueprint**
- подключи GitHub-репозиторий с этим проектом

Render увидит файл `render.yaml` и сам подставит настройки.

## 3. Нажми Deploy
Через 2–5 минут приложение поднимется.

## 4. Открой ссылку сервиса
Приложение будет доступно по постоянному адресу `https://<your-service>.onrender.com`

## Ограничения бесплатного плана Render
- сервис может "засыпать" после простоя
- первый запуск после сна может занимать 30–60 секунд
- SQLite хранится в файловой системе контейнера и может сбрасываться после redeploy

## Как не терять историю результатов
Есть 3 варианта:
1. терпеть сбросы на MVP-этапе
2. подключить платный persistent disk в Render
3. заменить SQLite на Supabase/Postgres/Firestore

## Переменные окружения для Google-входа
Если захочешь включить Google-логин через Firebase, добавь в Render:
- `FIREBASE_SERVICE_ACCOUNT` — путь к файлу внутри контейнера не подойдёт, лучше перейти на JSON через secret file или заменить логику на строковый JSON
- `FIREBASE_API_KEY`
- `FIREBASE_AUTH_DOMAIN`
- `FIREBASE_PROJECT_ID`
- `FIREBASE_STORAGE_BUCKET`
- `FIREBASE_MESSAGING_SENDER_ID`
- `FIREBASE_APP_ID`

Для быстрого продакшена можно пока оставить гостевой режим.

## Локальный запуск
```bash
pip install -r requirements.txt
uvicorn backend:app --reload --host 0.0.0.0 --port 8000
```
